Research

TMLR 2026

Complete Cyclic Subtask Graphs for Tool-Using LLM Agents: Flexibility, Cost, and Bottlenecks in Long-Horizon Workflows

Luay Gharzeddine, Samer Saab Jr. · Transactions on Machine Learning Research, 2026

Long-horizon tool-using tasks sometimes benefit from revisiting earlier subtasks, but revisiting costs routing, coordination and tokens. The paper studies complete cyclic subtask graphs, in which every subtask can hand off to every other and a single router picks each transition by checking natural-language criteria, and compares them with ReAct and dependency-ordered graphs on TextCraft, ALFWorld and Finance-Agent.

Cyclic graphs raise ALFWorld success from 33.8% (ReAct) to 58.2%, and the benchmark-generic graph keeps 87-96% of its TextCraft success when half of its routing decisions are replaced at random. ReAct stays stronger and cheaper on TextCraft; the paper maps where revisiting pays for itself and what it costs.

cyclic_task_graphs

The paper's reference implementation and full experiment harness.

A workflow controller in which every subtask can transition to every other, compared against ReAct and dependency-ordered DAGs. Every table and ablation in the paper (about 33,600 episodes across eight experiment families) reproduces from YAML configs, with dry-run cost estimates, spend caps, resumable runs and an analysis CLI that regenerates the paper's tables.

text2sql-cfg

Text-to-SQL where the model cannot write an unsafe query.

The model can only write SQL through an OpenAI custom tool constrained by a Lark grammar built from the database schema, so writes, stacked statements, comments and unknown columns cannot be sampled at all. Three more layers assume the grammar failed anyway: an AST validator, a read-only sandboxed executor, and tenant scoping injected by the server, so the model never sees a tenant id. Every number reproduces offline from a committed response cache, with no API key.

  • 85.2%held-out accuracy on corrected BIRD Mini-Dev labels (68.0% on original labels)
  • $0.0014per question
  • 0 of 275adversarial attacks reached the database or leaked tenant data

ditto

Extract a whole website into JSON with about one LLM call per page template.

ditto clusters a site's pages by template, shows an LLM one compressed page per template, and gets back reusable XPath specs. It verifies every selector on every page, repairs what fails, and then extracts the whole site with no LLM at all. Benchmarked on SWDE, a Common Crawl silver set and live sites against Crawl4AI, AutoScraper, per-page LLM extraction and hand-written XPath.

  • 0.846F1 on the SWDE test split, vs 0.845 for per-page LLM extraction
  • $0.08per 1,000 pages, vs $22.59
  • ~290xcheaper at the same accuracy
