# luaygz.com

Personal site of Luay Gharzeddine, served by GitHub Pages at https://www.luaygz.com (luaygz.com redirects there).

Plain static HTML and CSS with no build step: edit `index.html` or `assets/style.css` and push to `main`.

- `CNAME`: custom domain for GitHub Pages
- `assets/img/og.jpg`: social preview image (1200x630)
